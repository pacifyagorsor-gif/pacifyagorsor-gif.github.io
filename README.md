# Pacify Agorsor — Academic Portfolio Website

A responsive, static HTML/CSS portfolio designed for GitHub Pages. It uses a geospatial-inspired visual identity and includes About, Research Areas, Selected Publications, Profiles, and Contact sections.

## Files

- `index.html` — site content and navigation
- `style.css` — responsive styling and visual design
- `assets/README-CV.txt` — instructions for adding your CV PDF

## Before publishing: add your CV

1. Save your CV as **`cv.pdf`**.
2. Upload it into the `assets` folder so the path is `assets/cv.pdf`.
3. The CV links in the website will then work.

If you do not want to publish a CV yet, you can temporarily remove or change the two links to `assets/cv.pdf` in `index.html`.

## Publish with GitHub Pages

1. Sign in to GitHub as `pacifyagorsor-gif`.
2. Create a **public** repository named exactly `pacifyagorsor-gif.github.io`.
3. Upload the contents of this folder to the repository root. Do not upload the enclosing `pacify-agorsor-website` folder itself; `index.html` should be visible at the top level of the repository.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose branch `main` and folder `/(root)`, then click **Save**.
8. Wait for the Pages deployment to finish. Your site should be available at:
   `https://pacifyagorsor-gif.github.io/`

GitHub notes that the first deployment can take several minutes.

## Update the site later

Edit `index.html` for text and links, and `style.css` for design changes. Commit the changes to `main`; GitHub Pages will publish the update.
